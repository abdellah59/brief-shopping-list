# brief-shopping-list

Il s'agit une page web qui permet de créer et gérer une liste de courses. L'utilisateur peut ajouter des éléments à sa liste, avec des options supplémentaires pour modifier ou supprimer des entrées

## Fonctionnalités

- AAjout d'éléments à la liste via un champ de saisie et un bouton "Ajouter".
- Suppression d'éléments de la liste.
- Édition d'éléments existants.
- Mise en forme améliorée avec SCSS.

## Comment l'utiliser

### En ligne : 

Voici le lien : [Page Ma Liste de Courses](https://abdellah59.github.io/brief-shopping-list/)

### En local : 

1. Cloner ce dépôt sur votre machine locale.
2. Ouvrir le fichier index.html dans votre navigateur.
3. Saisir un élément dans le champ de texte.
4. Cliquer sur le bouton "Ajouter" pour l'ajouter à la liste.
5. Utiliser les options de suppression ou d'édition si disponibles.

## Objectifs pédagogiques

- Manipuler le **DOM en JavaScript**
- Gérer les **événements utilisateur** (clics)
- Créer une interface **dynamique et responsive**
- Utiliser **SASS** pour organiser et maintenir le style
